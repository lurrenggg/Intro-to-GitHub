# Intro-to-GitHub
A simple repository created to practice the basic features of Git and GitHub.

## 🎯 Purpose

The purpose of this repository is to practice and understand how to:

- 📁 Create and organize a GitHub repository
- 📝 Add and manage project files
- 💾 Track changes using commits
- 🌿 Understand branches and merging
- 🔄 Clone and update a repository locally
- 🚀 Push local changes back to GitHub
